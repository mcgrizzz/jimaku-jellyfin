Jimaku

Finds Japanese subtitles on jimaku.cc, checks each candidate against your media's actual timing, corrects it where that is safe, and writes it as an external sidecar. When it cannot establish confidence, it writes nothing and tells you why.

Verification

A candidate is only attached when its timing demonstrably matches this episode. These thresholds decide how much evidence is enough. On synthetic tests the worst wrong-episode match scored 0.28 correlation and 1.03 uniqueness, while correct matches scored 1.00 and 1.51; the defaults sit between those.

When several unrelated subtitles all need the same correction, that offset describes the reference track's own lead-in rather than any fault in the subtitles, and applying it shifts a well-timed file out of sync. Each subtitle's individual error is still applied.
A subtitle needing more than this is more likely the wrong file than a badly timed right one.
Candidates are tried in filename-match order, but a poor filename never excludes one: Jimaku uploads are named after the release they came from, which often has nothing in common with your file's name, so a low-scoring candidate is frequently the one that matches. Timing decides.
Handles PAL and NTSC conversions, where timings drift steadily rather than sitting at a constant offset. Karaoke and animation tags are rescaled to match.
Splits the subtitle into sections with separate offsets, for broadcast versus disc releases where footage was added or removed.

Scheduled sweep
Runs daily. Trigger it manually from Dashboard → Scheduled Tasks.
Jimaku gains uploads over time, so a decline is a statement about today rather than forever.
Jimaku allows 25 requests a minute and the plugin waits rather than exceeding it, so a sweep cannot break the limit — but a large library can keep it saturated for hours. Capping the run spreads the work over successive days; each day resumes where the last left off.
After one full pass, the episodes worth revisiting are the new ones. Set this to turn the daily sweep into a watch for newly added content.
Select none to sweep everything. Narrow this if the server holds non-anime content.
Notifications
Jellyfin's own subtitle dialog says "download queued" and then nothing. This pushes a short message to the session that asked, once the work has actually finished. Clients that do not support server messages simply ignore it.
Successes are always recorded. Declines are recorded only when you asked for them, so an unattended sweep over a library Jimaku has little for does not drown the feed.
Series memory
Only ever a file this plugin recorded writing, or one carrying its own stamp; a subtitle you placed yourself is never touched. Without this, replacing a subtitle leaves the old one behind under a .1. counter and the player may pick either.
The sidecar's own name is dictated by Jellyfin and cannot record which Jimaku upload it came from, so a comment in the file says it instead. ASS only — SubRip has no comment syntax.

Broadcast and disc releases of the same episode are routinely cut differently, so a subtitle timed for a web stream fits a Blu-Ray poorly however well its cue starts happen to line up. This only breaks a close call — a measurably better match from the other source still wins.
Release groups are consistent across a season, so once you have picked the same group by hand a couple of times, later episodes prefer it — but only to break a close call, never over a measurably better match. Only your own picks count: a subtitle the plugin chose confirming the preference that chose it would just be marking its own work. Deleting a subtitle counts against its group.
